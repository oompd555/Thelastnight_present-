What are naming conventions?

🏷️ A variable name

A variable is a named box that stores a value. Its name should say what is inside.

Naming conventions are agreed ways to name things, so everyone does it the same way.

Three common naming styles

snake_case

student_name
student_name = "Alex"
total_marks = 85

Lowercase words joined by underscores. For variables and functions.

PascalCase

StudentRecord
class StudentRecord:
    pass

class BankAccount:
    pass

A capital letter starts each word. For class names.

UPPER_SNAKE_CASE

MAX_MARKS
MAX_MARKS = 100
PI_VALUE = 3.14159

All capitals with underscores. For constants.

These are Python naming conventions. They are not different programming languages.

Function

A machine that performs a task.

    pass

📐

Class

A blueprint for creating objects.

    pass

🔒

Constant

A named value treated as fixed.

MAX_MARKS = 100

Use UPPER_SNAKE_CASE.

pass is a placeholder statement. It means “do nothing yet”, so the block is not empty.

The lock is a promise, not a rule: Python does not stop you from reassigning MAX_MARKS.

Meet PEP 8

PEP 8 is Python’s style guide: recommendations that help programmers write consistent, readable code. (PEP means Python Enhancement Proposal.)

PEP 8 is advice about style. It does not make programs faster or guarantee bug-free code.

Indentation: why spaces matter

Indentation is the space at the start of a line. It shows which statements belong inside an if, a loop, or a function. PEP 8 recommends four spaces per level.
